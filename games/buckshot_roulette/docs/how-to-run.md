# Buckshot Roulette: запуск, управление, обучение

[README](../../../README.ru.md) · English summary: [README.md](../../../README.md)

Все команды выполняются из корня репозитория (Windows, PowerShell или любой терминал).

## Требования

| что | версия | зачем |
|---|---|---|
| Buckshot Roulette (Steam) | v2.2.0.6, сборка 16736575, Godot 4.1.1 | игра; на этой версии проверено всё ниже (`game.toml`) |
| Python | 3.14 | весь код |
| `torch`, `numpy` | любые свежие | нейросети, симулятор |
| `matplotlib`, `tensorboard` | по желанию | графики, живые кривые обучения |
| `ffmpeg` | 9.0.2 essentials (gyan.dev) в `tools/ffmpeg/ffmpeg.exe` | по желанию: видео рекордных ранов |

Мост читает скрипты игры по именам, поэтому после обновления игры его нужно проверить
(`docs/modding-knowledge.md`).

## 1. Подготовка: копия игры
ИИ работает только с копией игры в `games/buckshot_roulette/game_copy/`; установленная игра не изменяется.
```
Copy-Item -Recurse "C:\Program Files (x86)\Steam\steamapps\common\Buckshot Roulette\Buckshot Roulette_windows" games\buckshot_roulette\game_copy
```
Перед первым запуском стоит сохранить резервную копию сохранений игры:
`%APPDATA%\Godot\app_userdata\Buckshot Roulette` → `games\buckshot_roulette\save_backup_<дата>\`.
Файл `override.cfg`, который подключает мост, `launch` записывает в копию сам.

## 2. Запуск игры с ИИ
```
python zero_player.py buckshot_roulette                         # модель по умолчанию (dx1.5)
python zero_player.py buckshot_roulette --model d3.1.3-s2 --speed 10 --mute
```
- `--model` — любая модель из `models/` (`python zero_player.py` выводит список), `--speed` — начальная
  скорость, `--mute` — без звука.
- Запускается копия игры с мостом и «мозг» ИИ. Интерфейс рисуется внутри игры.
- При старте ИИ выключен: игра идёт как обычно, слева видна только панель патронов.
- Остановить мозг ИИ — Ctrl+C в терминале (игра продолжит работу); закрыть игру — Alt+F4.

### Управление

| клавиша | действие |
|---|---|
| **[F1]** | включить/выключить ИИ. Включённый ИИ появляется справа и работает пошагово |
| **[Пробел]** | пошагово: ИИ делает ход (можно сыграть ход самостоятельно — ИИ пересчитает); в авто — пауза |
| **[Ctrl+Пробел]** | авто ↔ пошагово |
| **[Ctrl+1/2/3/4]** | скорость ×1 / ×3 / ×10 / ×20 |
| **[I]** | окно «почему»: что на столе повлияло на выбор хода (зелёное — за, красное — против) и коэффициенты; справа — предметы обеих сторон |
| **[N]** | нейросеть: активность нейронов и самые сильные связи к выбранному ходу |
| **[F11]** | полноэкранный ↔ оконный режим (если изображение смещено вправо вниз — нажать дважды) |
| **[~]** | режим разработчика: консоль (`help`), [F2]/[F3] — окна I/N, [PgUp]/[PgDn] — смена модели |

Стрелки остаются за игрой (выбор предметов с клавиатуры).

### Что показывает интерфейс
- **Слева (патроны):** приз и «раунд a/b» — выиграно раундов / сколько нужно для приза больше 1 000 000;
  «в ружье» — какие патроны есть; «порядок» — каждый патрон по очереди (серый — неизвестен, цветной — виден,
  тёмный — следует из подсчёта, жёлтая черта — патрон в стволе); «вылетели»; жизни; наручники и пила; что
  использовал дилер.
- **Справа (ИИ):** выбранный ход и шанс выиграть раунд. Жёлтая полоска — выбранный ход, серые — следующие
  варианты. Отметки |—| на концах полосок — разброс оценок соседних версий сети (dx1.3/dx1.4 для dx1.5,
  другие seed'ы для d…-s2): если отметки двух ходов перекрываются, сеть не уверена в выборе. Для адреналина
  в скобках указан предмет, который будет взят. Во время хода дилера карточка затемняется.

### Команды консоли [~]

| команда | действие |
|---|---|
| `models`, `model <имя>` | список моделей, смена модели |
| `speed <x>`, `ai on\|off`, `auto on\|off`, `i`, `n` | скорость, ИИ, режим, окна |
| `hp <n>`, `hp dealer <n>` | жизни игрока / дилера |
| `kill dealer` | завершить раунд победой (только в ход игрока) |
| `shells live blank …` | задать патроны в ружье |
| `remove <предмет> [dealer]` | убрать предмет со стола |
| `cheat order` | показать порядок патронов (только на экране; ИИ эти данные не получает) |
| `achievement on\|off`, `achievement` | режим достижения и его статус (см. ниже) |
| `record on\|off\|test` | запись ранов (см. ниже) |
| `realtime on\|off` | выбор хода на ×1, анимации на выбранной скорости (по умолчанию вкл) |
| `mute`, `unmute`, `clear` | звук, очистка консоли |

Партии с `cheat order` записываются с пометкой `(cheats)`, с командами, меняющими стол, — `(dev)`.

## 3. Режим достижения «1 000 000 и умер»
`achievement on` включает выдачу одного достижения Steam по правилу самой игры: смерть в Double or Nothing с
призом больше 1 000 000. Условия: ИИ включён ([F1]) на протяжении всей партии, без команд, меняющих стол, и
без `cheat order`. Таблица рекордов остаётся выключенной. В этом режиме:
- ран перезапускается (как удержание R), если первый приз окажется меньше 31 250 — с таким призом до
  1 000 000 нужно 21 раунд вместо 18;
- ИИ не делает паузу перед ходом: таймер первого приза считает игровое время.

## 4. Запись рекордных ранов
`record on` записывает каждый ран (кадры игры и звук) и сохраняет его, только если он побил рекорд (от 12
пройденных раундов); остальные удаляются. Когда ран может побить рекорд, игра замедляется до ×1.
Сохранённый ран превращается в MP4:
```
python -m games.buckshot_roulette.recordings
```
Видео: `games/buckshot_roulette/reports/ui/recordings/record_<раунды>r_<дата>.mp4` (хранится только рекорд).
`record test` сохраняет следующий ран отдельно (`test_…`), не затрагивая рекорд.

## 5. Результаты партий
```
python -m games.buckshot_roulette.livecheck      # последняя сессия: как ИИ видел стол, какие ходы выбирал
python -m games.buckshot_roulette.report         # обучения и партии на настоящей игре
```
- `reports/games.csv` — каждая партия: кто играл (модель; `human (hints …)` — человек с подсказками;
  `human + …` — вместе), раунды, приз, как закончилась (`death`, `restart`, `closed`).
- `reports/live_thoughts/*.jsonl` — каждое решение ИИ на игре.

## 6. Обучение в симуляторе
```
python -m games.buckshot_roulette.train --games 100000 --run d4 --items --agent dqn --shaping hp_events_items
python -m tensorboard.main --logdir games/buckshot_roulette/models     # кривые: http://127.0.0.1:6006
```
- Награды (`--shaping`): `none`, `hp_potential`, `hp_speed` (d3), `hp_events` (d2.1), `hp_events_items` (d3.1),
  `v4` (d4.x). Для d4.x также `--obs 2 --gamma 0.99 --n-step 3` (расширенное наблюдение, дисконт, n-step).
- `--seed <n>` — другой случайный старт (проверка, что результат не случаен); `--tables 32` — 32 партии
  параллельно (примерно вдвое быстрее).
- Несколько seed'ов сразу:
  ```
  python -m games.buckshot_roulette.multiseed --run d4.1.3 --seeds 0 1 2 -- --games 100000 --items --agent dqn --shaping v4 --obs 2 --gamma 0.99 --n-step 3 --tables 32
  ```
- Имена версий: `d<идея>.<правка>.<способ>`, способ: 0 — обычный, 1 — несколько seed'ов, 2 — несколько
  столов, 3 — оба.

## Неполадки

| симптом | причина и решение |
|---|---|
| «the bridge didn't answer» | игра не запустилась или нет копии игры в `game_copy/` |
| справа «мозг ИИ не подключён» | игра открыта, но мозг ИИ не запущен — запустить `zero_player.py` снова (подключится к открытой игре) |
| ИИ остановился на одном месте | Ctrl+C и повторный запуск; отказанные клики записываются в `reports/live_thoughts/` |
| изображение смещено вправо вниз | особенность полноэкранного режима игры: [F11] дважды |
| после обновления игры мост не работает | изменились имена в скриптах игры: см. `docs/modding-knowledge.md` |
