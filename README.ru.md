# zero_player

[English version](README.md)

ИИ, который сам учится играть в видеоигры, — по модулю на каждую игру.
Первый играет в **Buckshot Roulette** (режим Double or Nothing), следующий — **Balatro**.

| игра | версия | статус | лучший результат |
|---|---|---|---|
| [Buckshot Roulette](games/buckshot_roulette/) | v2.2.0.6 (сборка Steam 16736575) | готово (этап 1) | dx1.5: 5.99 раунда за партию в симуляторе (выигрывает 85.7 % раундов); на настоящей игре чистый ран ИИ прожил 24 раунда и получил достижение Steam «1 000 000 и умер» |
| Balatro | — | следующая | — |

```
python zero_player.py                         # игры, их версии и модели
python zero_player.py buckshot_roulette       # запустить копию игры с ИИ (модель по умолчанию dx1.5)
```
Как запускать всё остальное: [games/buckshot_roulette/docs/how-to-run.md](games/buckshot_roulette/docs/how-to-run.md).

## Устройство
```
zero_player.py      запускает игру с моделью (читает games/<игра>/game.toml)
core/               общее для всех игр: «мысль» ИИ, протокол мозг ↔ игра
games/<игра>/       всё про одну игру: мод (мост), симулятор, агенты, модели, отчёты, документы
```
Самих игр, их декомпилированного кода, сырых логов и видео в репозитории нет (см. `.gitignore`): только наш
код, лучшие обученные сети и итоги.

## Правила проекта
- Только одиночная игра: без мультиплеера и таблиц рекордов (мод выключает таблицу рекордов).
- ИИ видит только то, что мог бы знать игрок; стратегию он находит сам.
- Модифицируется копия игры, а не установленная.
