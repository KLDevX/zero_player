# Как запускать самому (шпаргалка для Акеля)

Все команды — в терминале в папке `C:\00_Workspace\02_player` (PowerShell или терминал VS Code).

## 0. Один раз: копия игры
Бот работает только с **копией** игры в `game_lab\game`, Steam-оригинал не трогаем. Копия уже есть.
Если её нет (новый компьютер, обновление игры):
```
Copy-Item -Recurse "C:\Program Files (x86)\Steam\steamapps\common\Buckshot Roulette\Buckshot Roulette_windows" game_lab\game
```
Сохранения игры сначала забэкапь: `%APPDATA%\Godot\app_userdata\Buckshot Roulette` → `game_lab\save_backup_<дата>`.
После обновления игры через Steam мост может перестать работать (поменялись имена в коде) — тогда зови меня.

## 1. Игра с ИИ внутри (одна команда)
```
python -m player.buckshot.launch
```
- Запускает копию игры и мозг ИИ (по умолчанию лучшая модель — dx1.5). Панели рисуются **прямо в игре**:
  слева патроны и что ты знаешь (вылетевшие патроны, что брал дилер, жизни), справа совет или ход ИИ
  с шансом выиграть раунд и двумя следующими вариантами.
- В начале ИИ **выключен**: чистая игра, слева только твоя память о патронах. Сам дойди до Double or Nothing
  (или включи ИИ — он пройдёт меню сам).

| клавиша | что делает |
|---|---|
| **[F1]** | ИИ вкл/выкл. Включённый появляется справа и начинает **пошагово** |
| **[Пробел]** | пошагово: ИИ делает свой ход (или сыграй сам — он подумает заново); в авто — пауза |
| **[Ctrl+Пробел]** | авто ↔ пошагово |
| **[Ctrl+1/2/3/4]** | скорость ×1 / ×3 / ×10 / ×20 |
| **[I]** | почему ИИ выбрал ход: что на столе толкнуло его «за» (зелёное) и «против» (красное), с коэффициентом; справа предметы |
| **[N]** | нейросеть: какие нейроны горят и самые сильные связи к выбранному ходу |
| **[F11]** | полноэкранный ↔ оконный. Если картинка уехала вправо вниз — нажми два раза |
| **[~]** | режим разработчика: консоль (`help`), [F2]/[F3] — окна I/N, [PgUp]/[PgDn] — модель |

Стрелки оставлены игре (ими выбирают предметы).

Справа: ход ИИ и шанс выиграть раунд; жёлтая полоска — его выбор, серые — следующие ходы. Чёрточки |—|
на конце полосок — погрешность: разброс ответов соседних версий сети (dx1.3/1.4 для dx1.5, другие seed'ы
для d…-s2). Если «усы» двух ходов перекрываются — сеть сама не уверена, какой лучше. При адреналине в
скобках — что он заберёт. Пока ходит дилер, карточка тускнеет.

Команды консоли: `model dx1.4`, `models`, `speed 5`, `ai on|off`, `auto on|off`, `hp 3`, `hp dealer 1`,
`kill dealer` (в твой ход), `shells live blank live`, `remove лупа` / `remove пиво dealer`, `cheat order`
(видеть порядок патронов — только тебе, ИИ его никогда не получает), `mute`, `unmute`, `clear`.
Партия с читами пишется как `(cheats)`, с изменением стола — `(dev)`.

**Достижение «1 000 000 и умер» для ИИ.** В консоли `achievement on` (по умолчанию выкл, `achievement` —
статус). Мост сам выдаст в Steam только это достижение, по правилу игры: смерть в Double or Nothing с
призом больше 1 000 000. Засчитывается только партия самого ИИ: [F1] включён всю партию, без команд,
меняющих стол, и без `cheat order`. Таблица рекордов остаётся выключенной.
С `achievement on` ран сам перезапускается (как удержание R), если первый приз выйдет меньше 31 250, а
бот не держит паузу перед ходом. Пока ты или ИИ выбираете ход, игра идёт на ×1, а анимации — на твоей
скорости: так таймер первого приза не съедается задержками бота (`realtime off` в консоли — выключить).
Сверху слева: «приз» (в первом круге — «≈», он тает, пока идёт таймер) и «раунд a/b» — выиграно раундов /
сколько нужно для приза больше 1 000 000 (каждый круг из 3 раундов удваивает первый приз).

- Другая модель: `--agent runs/<версия>/dqn_<партий>.pt` (лучший обученный «сам» —
  `runs/d3.1.3-s2/dqn_100000.pt`, старые версии — в `runs/archive/`, все результаты — `docs/models.md`). Стартовая скорость: `--speed 10`. Без звука: `--mute`.
- Слева: «в ружье» — какие патроны есть, «порядок» — каждый по очереди (серый — неизвестен, цветной —
  знаешь, тёмный — понятно по счёту; жёлтая черта — тот, что в стволе), «вылетели».
- Мышку можно трогать, когда ИИ выключен; когда он ходит, лучше не кликать по столу.
- Остановить мозг — Ctrl+C в терминале (игра останется). Закрыть игру — Alt+F4.
- Каждая партия пишется в `reports/games.csv` с тем, кто играл: модель, `akel (hints …)` или `akel + …`.

## 3. Посмотреть, как сыграл
```
python -m player.buckshot.livecheck        # последняя сессия: правильно ли ИИ видел стол, какие ходы выбирал
python -m player.report                    # все обучения + партии на настоящей игре (таблица внизу)
```
Файлы: `reports/games.csv` — каждая партия; `reports/live_thoughts/*.jsonl` — каждая мысль на игре.

## 4. Обучить новую версию (без игры, в симуляторе)
```
python -m player.buckshot.train --games 100000 --run d4 --items --agent dqn --shaping hp_events_items
python -m tensorboard.main --logdir runs     # живые графики: открой http://127.0.0.1:6006
```
Награды (`--shaping`): `none`, `hp_potential`, `hp_speed` (d3), `hp_events` (d2.1), `hp_events_items` (d3.1),
`v4` (d4.x). Для d4.x ещё `--obs 2 --gamma 0.99 --n-step 3` (новое наблюдение, дисконт, n-step).
`--seed 1` — другой случайный старт (чтобы проверить, что результат не везение).
`--tables 32` — играть 32 партии сразу (≈ в 2 раза быстрее). Несколько seed'ов сразу:
```
python -m player.buckshot.multiseed --run d4.1.3 --seeds 0 1 2 -- --games 100000 --items --agent dqn --shaping v4 --obs 2 --gamma 0.99 --n-step 3 --tables 32
```
Названия: d‹идея›.‹правка›.‹способ›, способ 0 — как раньше, 1 — несколько seed'ов, 2 — несколько столов, 3 — оба.

## 5. Разобрать версию и нарисовать отчёты
```
python -m player.buckshot.replay runs/d4/dqn_100000.pt     # логи партий + тактики + ошибки
python -m player.buckshot.viz compare d3.1 d4               # картинки сравнения в reports/
python -m player.buckshot.viz curves                        # кривые обучения
python -m player.buckshot.viz network runs/d4/dqn_100000.pt # картинка нейросети
```

## Если что-то не так
- «the bridge didn't answer» — игра не открылась или в `game_lab\game` нет `override.cfg`
  (launch сам его копирует; файл-исходник: `player\buckshot\bridge\override.cfg`).
- Бот застрял на одном месте — Ctrl+C и запусти `launch` снова: он подключится к уже открытой игре.
- Справа «мозг ИИ не подключён» — игра открыта, а `launch`/`ingame` не запущен.
- Картинка уехала вправо вниз — это баг полноэкранного режима игры: нажми [F11] два раза.
